# Troubleshooting: "Parcel not found in system"

## Error Message
```
127.0.0.1:8000 says
Parcel not found in system. Please check the waybill number.
```

---

## Cause 1: Waybill Not Generated Yet ❌

### Problem:
Order exists but waybill number hasn't been generated by the seller.

### Check:
```sql
SELECT id, waybill_number, status 
FROM orders 
WHERE id = [order_id];
```

If `waybill_number` is `NULL`, the waybill hasn't been generated.

### Solution:
**As Seller:**
1. Go to Seller Orders page
2. Find the order
3. Click "Generate Waybill" button
4. Copy the generated waybill number (format: `MIMWB-YYYYMMDD-ORDERID-XXXX`)

**Or via Tinker:**
```php
php artisan tinker
$order = Order::find([order_id]);
$waybill = $order->generateWaybillNumber();
echo $waybill;  // Copy this number for scanning
```

---

## Cause 2: Wrong Waybill Number ❌

### Problem:
Typing error or scanning wrong barcode.

### Common Mistakes:
- ❌ `MIMWB-20261107-00000026-A4F2` (correct)
- ❌ `MIMWB-20261107-0000026-A4F2` (missing one zero)
- ❌ `MIMWB-20261107-00000026-A4f2` (lowercase 'f')
- ❌ `MIMWB-20261107-00000026-4F2` (missing 'A')

### Solution:
1. **Copy-paste** the waybill number instead of typing
2. Use the **scanner** to avoid manual entry errors
3. Verify the waybill format: `MIMWB-YYYYMMDD-8DIGITS-4CHARS`

### Check if waybill exists:
```php
php artisan tinker
Order::where('waybill_number', 'MIMWB-20261107-00000026-A4F2')->first();
// If null, waybill doesn't exist in system
```

### List all existing waybills:
```sql
SELECT id, order_number, waybill_number, status
FROM orders 
WHERE waybill_number IS NOT NULL
ORDER BY created_at DESC
LIMIT 20;
```

## Cause 3: Order Not in Database ❌

### Problem:
The order ID doesn't exist at all.

### Check:
```sql
SELECT COUNT(*) FROM orders WHERE id = [order_id];
```

If count is 0, order doesn't exist.

### Solution:
1. Verify the order number (format: `MIM-00000026`)
2. Check if buyer actually placed the order
3. Check in correct database environment (dev vs production)

---

## Cause 4: Parcel Not Assigned to This Courier ⚠️

### Problem:
Parcel is assigned to a different courier company.

### Error message would be:
```
This parcel is assigned to a different courier company.
```

### Check:
```sql
SELECT 
    o.id,
    o.waybill_number,
    o.assigned_courier_id,
    c.company_name as assigned_courier
FROM orders o
LEFT JOIN users c ON o.assigned_courier_id = c.id
WHERE o.waybill_number = 'MIMWB-20261107-00000026-A4F2';
```

### Solution:
- Contact logistics to reassign the parcel
- Or login as the correct courier company

---

## Cause 5: Scanner Not Working 🔍

### Problem:
Scanner is active but not reading correctly.

### Check Scanner Status:
Look for indicator on screen:
- ✅ "Scanner Ready" with green dot = OK
- ⚪ "Scanner Inactive" = Camera permission denied

### Solutions:

**1. Camera Permission Denied:**
- Browser will ask: "Allow camera access?"
- Click "Allow"
- Refresh the page if needed

**2. Scanner Not Detecting QR Code:**
- Make sure QR code is clear and in focus
- Adjust lighting (not too bright, not too dark)
- Try moving closer/farther from code
- Make sure code is flat, not wrinkled

**3. Scanner Library Not Loaded:**
Check browser console for errors:
```
Failed to load html5-qrcode library
```

**Solution:**
```bash
# Reinstall the scanner library
npm install html5-qrcode
npm run build
```

**4. Use Manual Entry:**
If scanner continues to fail:
1. Click "Manual Entry" option
2. Type or paste waybill number
3. Click "Confirm"

## Cause 6: Order Status Not Ready 📦

### Problem:
Order status is not at the right stage for scanning.

### Check order status:
```sql
SELECT id, waybill_number, status, tracking_status
FROM orders 
WHERE waybill_number = 'MIMWB-20261107-00000026-A4F2';
```

### Required Status Flow:
1. ✅ `pending` → Can't scan yet (not packed)
2. ✅ `paid` → Can't scan yet (not packed)
3. ✅ `packed` → Logistics can confirm
4. ✅ `shipped` → Can be assigned to courier
5. ✅ `in_transit` → Courier can scan ✓
6. ✅ `completed` → Already delivered (no need to scan)

### Solution:
Wait for order to reach `in_transit` status (assigned and accepted by courier).

## Quick Diagnostic Commands

### 1. Check if order exists with waybill:
```bash
php artisan tinker
$order = Order::where('waybill_number', 'MIMWB-20261107-00000026-A4F2')->first();
if ($order) {
    echo "Order found: {$order->id}\n";
    echo "Status: {$order->status}\n";
    echo "Assigned to courier: {$order->assigned_courier_id}\n";
} else {
    echo "Order not found\n";
}
```

### 2. List recent orders with waybills:
```bash
php artisan tinker
Order::whereNotNull('waybill_number')
    ->orderBy('created_at', 'desc')
    ->take(10)
    ->get(['id', 'waybill_number', 'status', 'tracking_status']);
```

### 3. Check scan history for waybill:
```bash
php artisan tinker
ShipmentScan::where('waybill_number', 'MIMWB-20261107-00000026-A4F2')
    ->with('facility')
    ->get();
```

### 4. Check courier's facilities:
```bash
php artisan tinker
$courier = User::find([courier_id]);
$courier->facilities;  // Should show list of facilities
```

## Prevention Tips

### For Sellers:
✅ Always generate waybill before marking as "packed"
✅ Print/display waybill clearly for logistics pickup
✅ Use barcode/QR code printer for best scanning results

### For Logistics:
✅ Verify waybill is generated before confirming parcel
✅ Double-check courier assignment
✅ Keep waybill labels clean and readable

### For Couriers:
✅ Test scanner before starting shift
✅ Have good lighting when scanning
✅ Keep camera lens clean
✅ Use manual entry as backup if scanner fails
✅ Verify waybill number if scan fails multiple times

### For System Admins:
✅ Ensure html5-qrcode library is installed
✅ Monitor error logs for scan failures
✅ Test scanner on different devices/browsers
✅ Keep waybill format consistent
✅ Regular database backups

## API Response Debugging

### Normal Successful Response:
```json
{
    "success": true,
    "message": "Parcel received successfully at Metro Manila Main Hub",
    "order_id": 26,
    "waybill_number": "MIMWB-20261107-00000026-A4F2"
}
```

### Error Responses:

**1. Parcel not found:**
```json
{
    "error": "Parcel not found",
    "message": "No parcel found with waybill number: MIMWB-20261107-00000026-A4F2. Please verify the waybill number and try again."
}
```

**2. Wrong facility:**
```json
{
    "error": "Unauthorized",
    "message": "This facility does not belong to your company."
}
```

**3. Wrong courier:**
```json
{
    "error": "Unauthorized",
    "message": "This parcel is assigned to a different courier company."
}
```
